# 🚀 Users Dashboard — Sistema Profissional Angular

Um sistema completo de gerenciamento de usuários desenvolvido com **Angular moderno**, focado em:

- ⚡ Performance
- 🎨 UX Premium
- 🏗️ Arquitetura escalável
- 🧪 Testes automatizados
- 🌍 Deploy moderno

Projeto criado para simular um ambiente corporativo real e demonstrar boas práticas de frontend moderno.

# 🚀 Como Rodar o Projeto

## 📦 Instalação

```bash
npm install
```

---

## ▶️ Executar localmente

```bash
ng serve
```

Acesse:

```bash
http://localhost:4200
```

---

## 🏗️ Build de produção

```bash
ng build --configuration production
```

---

# 🌍 Deploy na Vercel

```bash
npm install -g vercel
vercel
```

---

# 🧪 Executar Testes

## Unitários

```bash
npm run test
```

## E2E

```bash
npx cypress open
```
